# HH Auto-Apply Assistant

Userscript для [Tampermonkey](https://www.tampermonkey.net/), который автоматически откликается на вакансии на hh.ru и пишет к каждому отклику сопроводительное письмо под конкретную вакансию с помощью ИИ (Google Gemini, Anthropic Claude или Alibaba Qwen).

Текущая версия: **5.4**

## Возможности

- **Автоотклик по списку вакансий.** Скрипт проходит по карточкам в поиске hh.ru, нажимает «Откликнуться» и отправляет отклик. Между откликами делаются случайные паузы 3–7 секунд, после 30 откликов скрипт останавливается (счётчик обнуляется кнопкой «Сброс»).
- **Письмо под вакансию.** Для каждой вакансии скрипт загружает описание и ключевые навыки, а ИИ пишет письмо: выделяет 2–3 главных требования и сопоставляет их с опытом из вашего профиля. Язык письма (русский или английский) выбирается по языку вакансии.
- **Резервный шаблон.** Если ИИ недоступен или ключ не указан, используется ваш шаблон с подстановкой `{vacancy_title}` и `{company_name}`. Можно работать и только на шаблоне.
- **Выбор резюме.** Нужное резюме выбирается в форме отклика по названию из вашего списка.
- **Другой регион или страна.** Предупреждение о переезде подтверждается автоматически, либо такие вакансии пропускаются (по настройке).
- **Вопросы работодателя.** Скрипт может пропускать такие вакансии или ставить работу на паузу и звать вас звуком и уведомлением.
- **Панель управления на странице:** статистика (просмотрено, откликов, пропущено), подробный лог, экспорт отчёта в CSV.
- **Продолжение после перезагрузки.** Если скрипт был запущен, он продолжает работу на новой странице.

## Установка

1. Установите расширение [Tampermonkey](https://www.tampermonkey.net/) для Chrome, Firefox, Edge или Safari.
2. Откройте ссылку на скрипт:
   [hhassistant.user.js](https://raw.githubusercontent.com/BlackOleg/hh.auto.assistant/main/hhassistant.user.js)
3. Tampermonkey покажет окно установки, нажмите **«Установить»**.
4. Обновление делается так же: откройте ссылку ещё раз и нажмите **«Обновить»**.

При первом обращении к API ИИ или к `api.hh.ru` Tampermonkey спросит разрешение на запрос к внешнему домену. Нажмите **«Разрешить всегда»**.

## Настройка

Откройте hh.ru, войдите в аккаунт, и в правом нижнем углу появится панель **HH Auto-Apply**. Нажмите **«⚙️ Настройки»**:

| Раздел | Что указать |
|---|---|
| Список резюме | Названия ваших резюме точно так, как они называются на hh.ru |
| ИИ-провайдер | Gemini, Claude или Qwen, API-ключ и модель |
| Профессиональный профиль | Ваш опыт, достижения и цифры. ИИ берёт факты только отсюда, поэтому чем конкретнее профиль, тем лучше письма |
| Шаблон письма | Резервный текст на случай, если ИИ недоступен |
| Креативность / длина | Temperature (0–1) и лимит токенов (рекомендуется 800–1200) |

### Где взять API-ключ

| Провайдер | Где получить ключ | Модели |
|---|---|---|
| 💎 Google Gemini | [aistudio.google.com/apikey](https://aistudio.google.com/apikey) (есть бесплатный лимит) | Flash, Flash-Lite, Pro |
| 🟠 Anthropic Claude | [console.anthropic.com](https://console.anthropic.com/) | Haiku 4.5, Sonnet 5.5, Opus 5.5 |
| 🔵 Alibaba Qwen | [Alibaba Cloud Model Studio](https://www.alibabacloud.com/product/modelstudio) | Turbo, Plus, Max |

API-ключи хранятся только в локальном хранилище Tampermonkey в вашем браузере и отправляются только выбранному провайдеру ИИ.

## Использование

1. Откройте на hh.ru поиск вакансий с нужными фильтрами.
2. На панели выберите режим письма («Умный ИИ» или «Статический шаблон»), резюме и действие при вопросах работодателя.
3. Нажмите **RUN AUTO-APPLY**. Остановить работу можно кнопкой **PAUSE AUTO-APPLY**.
4. Следите за логом. В нём видно, загрузилось ли описание вакансии, на каком языке и каким ИИ сгенерировано письмо и отправлен ли отклик.

Обработанные карточки подсвечиваются зелёной рамкой с меткой **SMART MATCH**.

## Как это работает

```
Карточка вакансии
  → проверка «уже откликались»
  → загрузка описания (страница вакансии → JSON страницы → api.hh.ru)
  → генерация письма ИИ (или шаблон)
  → «Откликнуться» → подтверждение региона → выбор резюме
  → вставка письма → отправка
```

## Решение проблем

| Симптом | Что проверить |
|---|---|
| Письмо по шаблону, а не от ИИ | Есть ли API-ключ и нет ли в логе ошибки провайдера (`HTTP 401` означает неверный ключ, `404` означает недоступную модель) |
| Письмо общее, без деталей вакансии | Есть ли в логе строка «✅ Описание загружено». Если описание не получено, ИИ пишет только по названию вакансии |
| Письмо обрезано | Увеличьте «Макс. длина (tokens)» в настройках |
| Скрипт «завис» на форме | Возможно, у вакансии вопросы работодателя или изменилась вёрстка hh.ru. Через 60 секунд скрипт переходит к следующей вакансии |
| Резюме выбирается не то | Название в списке резюме должно совпадать с названием на hh.ru |

## Важно

- Используйте скрипт ответственно: массовые однотипные отклики могут раздражать работодателей и нарушать правила hh.ru. Лимит и паузы между откликами заложены специально.
- Вёрстка hh.ru периодически меняется. Если что-то перестало работать, создайте issue и приложите лог из панели.
- Запросы к API ИИ оплачиваются по тарифам выбранного провайдера.
